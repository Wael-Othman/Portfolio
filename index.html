⚙️ How every position is calculated

1
Current Value (USD) = currentPrice(local) × shares × FX_rate(USD per 1 local unit)
For USD positions, FX_rate = 1.0 exactly. Foreign positions use live rates fetched from exchangerate-api.com.
2
Gain / Loss ($) = currentValue(USD) − amountInvested(USD)
3
Return % = (Gain/Loss ÷ amountInvested) × 100
4
Allocation % = (positionValue ÷ totalPortfolioValue) × 100 — recalculated live on every refresh.
5
Auto-refresh: prices update every 5 minutes automatically while the tab is open. Stocks via Yahoo Finance, crypto via CoinGecko, FX via exchangerate-api. A countdown timer is shown in the status bar.

📐 Core formulas with examples

USD Position
Value = Price × Shares
NVDA: $215.20 × 20.92 = $4,502
EUR Position
Value = Price(€) × Shares × EUR/USD
Deutsche Telekom: €27.40 × 23.72 × 1.175 = $764
HKD Position
Value = Price(HK$) × Shares × HKD/USD
JD.com: HK$117.50 × 108.29 × 0.1277 = $1,625
NOK Position
Value = Price(kr) × Shares × NOK/USD
Aker BP: kr333.27 × 40 × 0.1087 = $1,448
GBX Position (pence)
Value = Price(p) × Shares × GBP/USD ÷ 100
Domino's: 192.5p × 310 × 1.358 ÷ 100 = $810
